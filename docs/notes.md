# 專案整理說明

## 已提供內容

- Flutter / Dart 前端主程式（加密貨幣趨勢、穩定幣風險指標、K 線與 API 資料串接）。
- 前端使用 http 套件取得後端摘要資料。

## 尚未納入

- 後端服務原始碼，以及模型訓練、推論與評估程式。
- 原始 Flutter 專案的 lockfile、平台建置資料。
- 實際 API 測試回應、完整測試報告與系統截圖。

## 整理原則

- 保留使用者提供的 Dart 畫面和資料處理邏輯。
- 只將寫死的後端 IP 改為 API_BASE_URL 建置參數。
- 不把示例數據當成真實預測；上漲分數不等同於機率。
- 不上傳 API 密碼、權杖或其他敏感資訊。
- 目前未進行 Flutter 編譯測試，需要在安裝 Flutter SDK 的環境確認。
